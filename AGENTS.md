# AGENTS.md

## Cursor Cloud specific instructions

This is a minimal Git tutorial repository containing standalone Python scripts (`hello.py`, `hola.py`, `bonjour.py`, `hej.py`). There is no build system, no package manager, no tests, no linter, and no services.

- **Run any script:** `python3 <script>.py` (e.g. `python3 hello.py`)
- **Python version:** Any Python 3.x works; no dependencies required.
- There are no services to start, no databases, and no external dependencies.
- `hej.py` is an empty file (placeholder).
