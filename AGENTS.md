# AGENTS.md

## Cursor Cloud specific instructions

This is a minimal Python tutorial repository with standalone scripts (`hello.py`, `hola.py`, `bonjour.py`, `hej.py`). There are no dependencies, no build system, no test framework, and no linting configuration.

### Running the application

```bash
python3 hello.py
python3 hola.py
python3 bonjour.py
python3 hej.py
```

### Notes

- Python 3.x is the only requirement (available in the VM by default).
- There are no package dependencies to install.
- There is no lint/test/build infrastructure; syntax can be validated with `python3 -m py_compile <file>.py`.
- `hej.py` is an empty file (expected).
